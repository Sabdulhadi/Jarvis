# UK — Innovator Founder visa (Plan C)

Tertiary track. Insurance + optionality. INDROX's deep-tech / dual-use profile is the angle.

## Vehicle

The **Innovator Founder visa** (replaced both the prior Startup and Innovator visas in 2023). Key features:

- Requires endorsement from an approved endorsing body
- No minimum investment amount (changed from prior Innovator £50k requirement — verify current rules)
- Business must be innovative, viable, scalable
- 3-year visa, leading to indefinite leave to remain (ILR)
- Spouse + dependents can be included
