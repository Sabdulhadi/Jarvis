## Path forward

1. **Push written French to B2 / NCLC 7.** Highest-leverage single action.
2. **Take or refresh English exam** if not on file.
3. **Complete ECA** (WES is the most common provider — typically 6-12 weeks).
4. **Create IRCC profile** once eligible — entry into the pool is free.
5. **Monitor category-based draws** — French-speaking draws are especially favorable.
