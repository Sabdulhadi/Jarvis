# Faceless AI content business

Zero-budget faceless content across 13 niches. Distribution: Instagram, YouTube (Shorts + long-form), Facebook.

## Stack

- **Voice:** ElevenLabs
- **Automation:** Make.com + n8n
- **Source-of-truth:** Airtable (videos pipeline)
- **Visuals:** TBD per niche (stock footage, AI image gen, screen recording)

## Status

- **Stage:** Active. Pipelines being refined.
- **Operating principle:** volume × consistency × hook quality > production polish

## Subfolders

- `niches/` — one folder/markdown per niche with audience, hook formulas, posting cadence, examples
- `pipelines/` — exported Make.com / n8n flow JSONs + written explainers
- `assets/` — recurring B-roll, music, voice profile IDs

## Current asks

1. **Document the 13 niches.** Each gets a brief in `niches/<niche-name>.md` so the `content-producer` agent can act.
