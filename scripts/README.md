# Scripts

Helper utilities for JARVIS workflows.

| Script | Purpose |
|---|---|
| `jarvis-voice.sh` | Voice layer skeleton (record → Whisper → Claude → ElevenLabs). Stubs only — wire per `SETUP.md` section 3 before using. |
| `new-raw.sh` | Create a timestamped raw note in `vault/raw/` and open in `$EDITOR`. |

Make scripts executable: `chmod +x scripts/*.sh`.
